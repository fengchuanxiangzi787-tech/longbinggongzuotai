# Longbing 个人工作台

面向校园日常的单文件网页，把绩点规划、实验数据、收支记录和日程安排放在同一个工作台里。下载 `index.html` 后用浏览器打开即可使用，免安装、免构建。

## 可以做什么

- **绩点规划**　录入课程和学分，切换绩点规则，按目标绩点反推期末需要的成绩。
- **实验数据**　整理表格，查看统计摘要和线性拟合结果，导出 CSV。
- **记账与日程**　记录收支，管理考试和作业截止时间，将日程导出为日历文件。
- **校园工具**　收藏常用网址，离线查看内置的校内时间表。

## AI 功能

在页面顶部的接口配置中填写支持 Chat Completions 的 Base URL、模型名和自己的 API Key。对话助手可以按问题引用工作台里的绩点、日程或收支摘要，也可以在聊天窗口关闭这项功能。

配置支持图片输入的模型后，可以从成绩单、实验记录、小票和校园通知截图中提取数据。识别时，浏览器会将所选图片发送至配置的模型服务。同一标签页会缓存最近的识别结果，重复上传同一图片时可复用结果。接口需要允许来自浏览器的跨域请求。

## 数据与备份

工作台记录保存在当前浏览器中。换设备、清理浏览器数据，或从本地文件迁移到线上网址前，可从首页的「备份」导出数据，再到新环境恢复。API Key 通过页面配置并保存在当前浏览器中，请勿写入公开仓库。

## 发布到 GitHub Pages

将 `index.html` 和 `README.md` 放在仓库根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，指定存放这两个文件的分支和 `/(root)`，保存后等待部署完成。
